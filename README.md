
# 🧮 C Calculator

A beginner-friendly calculator built using C programming.

## 👋 About Me

I am **B. Abhishek**, a **1st-year B.Tech CSE student** at the **Central University of Andhra Pradesh**.

This is my first-ever programming project, built while learning the fundamentals of C.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Continuous calculations
- Division-by-zero protection
- Invalid operator handling

## 🧠 Concepts Used

- Variables and data types
- `printf()` and `scanf()`
- `if-else` and `else if`
- `do-while` loop
- Functions
- Arithmetic operators
- Basic error handling

## 💻 How It Works

The program takes a first number, an operator, and another number. It performs the calculation and stores the result in the `total` variable.

The user can continue performing calculations using the previous result until they choose to stop. Finally, the program displays the final result.

This project helped me understand how different C programming concepts work together to build a functional program.
